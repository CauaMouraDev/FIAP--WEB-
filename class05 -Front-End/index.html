Estudo de Pseudo-classes e Pseudo-elementos em CSS

Checklist de estudo

  • ✓ :hover = quando o mouse passa por cima
  • ✓ :active = quando clica no elemento
  • ✓ :visited = link já acessado
  • ✓ :focus = elemento em foco
  • ✓ :first-child / :last-child = primeiro e último filho
  • ✓ :nth-child(odd) = elementos ímpares
  • ✓ :not(.classe) = exceto a classe informada
  • ✓ :checked = checkbox marcado
  • ✓ :valid / :invalid = e-mail válido ou inválido
  • ✓ :required = campo obrigatório
  • ✓ :disabled = campo bloqueado
  • ✓ ::first-letter = primeira letra
  • ✓ ::first-line = primeira linha
  • ✓ ::selection = texto selecionado

1) :hover

Passe o mouse aqui

Exemplo: quando o mouse passa por cima, a caixa muda de cor.

2) :active

Clique aqui

Exemplo: o link muda de cor quando é clicado.

3) :visited

Link visitado

Exemplo: links já acessados recebem outro estilo.

4) :focus

Exemplo: o campo fica com fundo amarelo quando recebe foco.

5) :first-child e :last-child

  • Primeiro item
  • Segundo item
  • Terceiro item
  • Quarto item
  • Último item

Exemplo: o primeiro item fica vermelho e o último fica azul.

6) :nth-child(odd)

  • Item 1
  • Item 2
  • Item 3
  • Item 4
  • Item 5
  • Item 6

Exemplo: os itens ímpares ficam verdes.

7) :not(.esse)

  • Este item tem classe especial
  • Outro item
  • Mais um

Exemplo: todos os itens que não têm a classe .esse recebem outra cor.

8) :checked

Exemplo: quando o checkbox está marcado, ele recebe um estilo diferente.

9) :valid e :invalid

Exemplo: email válido fica verde e inválido fica laranja.

10) :required

Exemplo: o campo obrigatório recebe destaque.

11) :disabled

Exemplo: campo desabilitado fica cinza.

12) :first-letter

Exemplo: a primeira letra do parágrafo recebe uma fonte e cor especiais.

13) ::first-line

Esta é a primeira linha do parágrafo, que recebe um efeito especial em CSS.

Exemplo: a primeira linha do texto recebe destaque visual.

14) ::marker

  • Item com marcador customizado
  • Outro item da lista
  • Mais um item

Exemplo: o marcador da lista pode ser estilizado com cor e tamanho diferentes.

15) ::selection

Selecione este texto com o mouse para ver a mudança de cor.

Exemplo: o texto selecionado recebe um fundo amarelo.
