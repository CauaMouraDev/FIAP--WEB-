Pseudo-classes e Pseudo-elementos

Entenda como o CSS consegue estilizar elementos em estados especiais ou partes específicas de um conteúdo.

1. Pseudo-classes mais usadas no CSS

2. Pseudo-elementos mais usados no CSS

Os pseudo-elementos criam ou estilizam partes do conteúdo. Eles usam dois pontos: ::.

Esse parágrafo mostra a primeira letra destacada e uma parte do texto com destaque visual.

Caixa com conteúdo extra

::before

Insere conteúdo antes do elemento.

Antes

::after

Depois

3. Exemplo prático com uma div

A pseudo-classe :hover muda o estado da div quando o mouse passa por cima. Já os pseudo-elementos ::before e ::after criam conteúdo visual antes e depois do texto sem mudar o HTML.

Exemplo com div

Aqui o CSS usa :hover para trocar a cor e ::before e ::after para inserir elementos visuais sem alterar a estrutura do documento. 


.box-pratica:hover {
  background: #f97316;
  color: white;
}

.box-pratica::before {
  content: "→ ";
}

.box-pratica::after {
  content: " ←";
}

4. Diferença principal

Pseudo-classes

  • Selecionam elementos por estado, posição ou condição.
  • Ex: :hover, :focus, :checked, :nth-child()
  • Usam 1 ponto.

Pseudo-elementos

  • Selecionam partes do conteúdo ou criam elementos virtuais.
  • Ex: ::before, ::after, ::first-letter, ::selection
  • Usam 2 pontos.

5. Resumo final

As pseudo-classes e pseudo-elementos são recursos muito importantes do CSS. As primeiras reagem ao estado do elemento e as segundas estilizam partes do conteúdo ou criam elementos visuais sem mexer no HTML.
